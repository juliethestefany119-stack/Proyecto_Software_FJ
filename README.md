**Curso:** Programación (Código: 213023) - Fase 4: Componente Práctico

**Programa:** Ingeniería de Sistemas  

## Descripción del Proyecto
Aplicación desarrollada en Python bajo el paradigma de Programación Orientada a Objetos (POO) sin uso de bases de datos. Implementa abstracción, herencia, polimorfismo, encapsulamiento y manejo avanzado de excepciones (`try/except/else/finally`, excepciones personalizadas y encadenamiento) junto con registro de auditoría en archivo `.log`.

## Estructura del Repositorio
* `main.py`: Código fuente principal con las clases (`Entidad`, `Cliente`, `Servicio`, `ReservaSala`, `AlquilerEquipo`, `AsesoriaEspecializada`, `Reserva`, gestor del sistema y simulación de 18 operaciones).
* `software_fj.log`: Registro automático de eventos (`INFO`) y errores controlados (`ERROR`).
* `README.md`: Documentación general del proyecto.

## Requisitos y Ejecución
* **Python 3.10 o superior**
* Para ejecutar el sistema desde la terminal:
```bash
python main.py
```
